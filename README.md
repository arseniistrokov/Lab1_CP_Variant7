# Лабораторная работа №1 — Компьютерное программирование (вариант 7)

Тема: использование операторов проверки условия и операторов цикла на языке Си.
Табулирование функции, заданной тремя выражениями; формат вывода зависит от
поразрядного выражения `(Ац | Вц) ^ (Ац | Сц)`.

Строков Арсений, гр. CR-263, Технический университет Молдовы.

## Содержимое

- `lab1/step1/my/my.c` — программа, написанная самостоятельно
- `lab1/step1/ai/ai.c` — программа, сгенерированная нейросетью DeepSeek
- `lab1/Makefile` — сборка обеих программ
- `flowchart.png` — блок-схема алгоритма
- `fig_*.png` — снимки экрана с результатами тестов
- `Отчет_по_лабораторной_работе_№1_Вариант_7.pdf` / `.docx` — отчёт
